# Mega Man Maker

Convert Mega Man levels between the [VGLC](https://github.com/TheVGLC/TheVGLC) ASCII format and the native Mega Man Maker `.mmlv` format.

Both conversions can be done by using these commands in order:

```
cd batch
MarioDiffusion.bat
```
Drag and drop a `.mmlv` or `.txt` file when prompted — it will automatically convert to the opposite format.

Automatic dowloads based on ID can be done by running these two commands in order:

```
cd batch
DownloadLevel.bat
```
Enter a level ID when prompted — it will download directly to your Mega Man Maker levels folder.
